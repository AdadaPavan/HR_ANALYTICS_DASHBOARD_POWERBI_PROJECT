# HR Analytics Dashboard (Power BI)

## 📊 Project Overview

This project presents an interactive **HR Analytics Dashboard** built in
Power BI to analyze employee attrition, workforce demographics, and
salary patterns.\
The dashboard helps HR teams identify trends, understand attrition
drivers, and support data‑driven decisions.

------------------------------------------------------------------------

## 🎯 Objectives

-   Analyze overall employee attrition
-   Identify high‑risk departments and roles
-   Understand salary and experience trends
-   Explore workforce demographics

------------------------------------------------------------------------

## 📁 Dataset

The dataset includes employee information such as: - Employee ID -
Department - Job Role - Salary - Years at Company - Education Field -
Attrition Status

------------------------------------------------------------------------

## 📌 Key Metrics (KPIs)

-   Total Employees
-   Attrition Count
-   Attrition Rate
-   Average Age
-   Average Salary
-   Average Years at Company

------------------------------------------------------------------------

## 📈 Dashboard Features

-   Attrition by Age Group
-   Attrition by Education Field
-   Attrition by Salary Slab
-   Attrition Trend by Years at Company
-   Attrition by Job Role
-   Interactive filters (Department)

------------------------------------------------------------------------

## 🛠 Tools Used

-   Power BI Desktop
-   DAX (Data Analysis Expressions)
-   Power Query

------------------------------------------------------------------------

## 🚀 How to Use

1.  Download the dataset
2.  Open Power BI Desktop
3.  Load the dataset
4.  Recreate visuals using provided measures
5.  Explore insights using filters
